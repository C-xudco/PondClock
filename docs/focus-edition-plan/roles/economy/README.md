# 第一版：专注、普通钓鱼与限次抽鱼的收益计划

2026-10-27（Asia/Shanghai）。状态：**待审批的数值方案；未改产品、存档或版本**。本次全部需求属于第一版，第二版尚未定义。角色独占本目录；输入是当前源码及上一轮冻结数值提案，输出是口径、候选参数与可复算结果，不负责产品命令实现。

## 已确认要求与未批准参数

用户要求第一版删除数值鱼竿升级；番茄计划完成奖励一包高级饵、完成一天奖励一次免费任意机票；普通咬钩及时点击必中，未点仍有20%–40%概率自动捕获；可停止/开始；特殊杆付游戏金币后启用主动抽鱼、限15次、平均2–3次挥杆咬钩，进度条白0%、红10%、黄50%、绿100%，特殊鱼品质更高。**用户已确认15次按进入收鱼进度条扣1次，空挥不扣。** 原来“成功收获后，本地鲜鱼＋道具直售长期平均约50金币”的口径继续列作普通钓鱼数值目标，不能改写为每次鱼讯保底50。

本角色建议的30%自动率、450金币/15次、各区间宽度、动画时间与品质倍率均是**待审批工程参数**。不因本目录计算通过而自动批准。上一轮的47种鱼调价与品质方案仍是待审批输入，不能冒充现版真实数值。第一版候选暂缓未实现的升级代币，其0.2%归还鱼，故鱼率97.4%、道具直售贡献0.233，另外四件新物各0.2%仍待审批。此前五新物97.2%仅作未实施的历史对照。

## 普通钓鱼：按相同在线时间比较

建议第一版用一个固定普通竿配置，等待55–125秒、平均90秒；沿用20秒响应窗口，去掉等级带来的速度、判定窗与品质加成。原先最多12%的闲置加速也建议停用，以免番茄挂机越久越快导致收益口径混乱。外观鱼竿仍可收藏，和数值升级是两个概念。

咬钩后，窗口内点击成功率100%（仍按鱼/拾物表决定收获种类）；无人点击时等待完整20秒，到期仅作**一次**自动成功判定。建议默认成功率30%，配置允许平衡在20%–40%内调整，不增加按天气或反复点设置刷概率的机制。失败无收获，重开不能重抽同一鱼讯，手动与自动对同一鱼讯至多结算一次。自动成功沿用普通鱼池及品质，不额外提高品质。

以下是条件毛收入50、手动平均2秒响应、在线连续钓鱼的理想比较，不包含游戏实际保存延迟：

| 方式 | 每次鱼讯毛期望 | 每小时毛期望 | 相对及时手动 |
| --- | ---: | ---: | ---: |
| 手动100%，平均2秒响应 | 50 | 1956.52 | 100% |
| 自动20%，等20秒窗口 | 10 | 327.27 | 16.73% |
| 自动30%，等20秒窗口 | 15 | 490.91 | 25.09% |
| 自动40%，等20秒窗口 | 20 | 654.55 | 33.45% |

公式：`E手动每小时=3600/(90+2)×50`；`E自动每小时=3600/(90+20)×p自动×50`。实际及时手动的响应时长在0–20秒，固定配置下自动每小时收益最多为同等收获品质手动的20%–40%，因此优势来自更多成功捕获和更快进入下一轮，而非暗中压低自动鱼价。

“收益”表示鱼篓里可按本地鲜鱼价出售的收获价值，**没有自动售卖或直接铸造金币**。未出售过168真实小时仍每鱼1金币。关闭软件/电脑睡眠不补算自动收获；后台最小化可在线运行，但恢复时不能因计时器一口气补发大量历史鱼讯。暂停态无收益，开始也不补之前的时间。鱼类、道具与保底只在成功结算时改变，漏鱼不增加高品质保底。

在上一轮待审价格和品质组合中，删去鱼竿升级、保留高级饵有无后，旧12区普通成功收获长期毛均值为**47.13–51.91**；无饵47.13–50.01。这是可延用的候选起点，必须在最终17水域鱼池/供给完成后重算，不能把12区的结果直接说成17区验收通过。

## 番茄奖励与饵的边界

建议首发固定每个计划25分钟，一天有效专注100分钟、即4个完整计划；首发不加入自定义时长。这些是待审的产品参数，按完成的计划而非单纯打开窗口累计。每个完整番茄奖励1包现有高级饵、每包作用于5次成功鱼获；计时、完成身份与奖励同事务保存，同一个计划完成事件重试不能再领一包。退出、暂停和睡眠是否计入有效专注必须由计时规则明确，不能客户端恢复一次就发奖励。

现版饵售价120/包并不等于免费奖励能赚120：旧待审数值下饵的现金边际提升远低于售价。应让用户明确选择是否使用高级饵；建议自动模式默认不用珍贵饵，避免专注时奖励被悄悄消耗，手动开启使用后再按成功鱼获扣次数。失败、空挥和拾物不耗饵；特殊抽鱼也不耗普通饵。旧饵库存与剩余次数完整保留。

每日免费旅行是一项降低出行支出的权益，不计入“每竿约50”现金毛收入。免费出票仍按目的地的真实游戏航线飞行时长到达，不能提现/转卖或消耗已有机票九折券；高价路线6000的减免价值也不应记成钓鱼赚钱。每日完成判定、是否跨日累计/可攒券及已持有未用券时的规则在主方案中另定，避免静默丢奖励。

## 特殊抽鱼：付费限次而非删掉的升级树

推荐把特殊杆设计为独立的可消耗15次许可：**450金币购买一组15次，旧组用尽后才允许再次购买**；第一次购买同时解锁入口，外观所有权与次数分开记录。450是候选价格，用户只明确了要花钱、没有批准金额。该杆没有等级升级，不能重走已删除的600/2600/9000升级树。

空挥次数建议在每轮开始时按2或3各50%抽定，平均2.5次；每次挥/收动画合计3秒，触发进度条时才扣1次。进度条超时建议6秒，本轮未按、停白或颜色内概率判定失败都耗本次；进入判定之前停止仅保留当前挥杆进度，不扣次数、不重抽鱼种/品质。15次用完保持普通钓鱼可用，必须显式购买新组，不能后台自动扣款。

颜色宽度建议白20%、红25%、黄30%、绿25%，区域边界由统一半开区间规则判定。用户的0/10/50/100%是**停在该区后的成功率**，不是区域宽度，也不是四个互斥掉率相加。指针匀速来回时，均匀随机时刻停针的数学对照成功率为`0.20×0+0.25×0.10+0.30×0.50+0.25×1=42.5%`；这不能预测真人水平，真人熟练度和指针速度要实机验证。

建议特殊模式仅出鱼，使用当前所在区域的鱼种供给，品质在普通**未保底**权重上分别乘：普通1、稀有1.25、史诗3.5、传说5，再归一化。特殊模式不消耗/累积普通30鱼软保底，避免提前垫保底再用高倍率套取；不消耗普通饵，与普通鱼/拾物的随机频道、事件ID和次数账本分开。这些都是新增建议，需审批。

按旧12区待审价格/品质模型，该组参数计算到的特殊鱼品质概率在各区均满足：稀有、史诗、传说**各自**高于同区普通长期含保底且有高级饵的对照。普通品质仍占多数；特殊传说约0.60%–1.35%。单条特殊成功鱼本地鲜售均值51.40–57.64，较同区普通无饵条件鱼均值提高约3.25–7.42。不能只把“倍率大于1”当作归一化后一定高于包含保底的普通玩法，复算器检查了真实比较。

| 15次一组、450金币成本 | 毛收入范围 | 减许可成本后 |
| --- | ---: | ---: |
| 每次都停绿并成功 | 771.02–864.62 | +321.02–414.62 |
| 均匀随机停针、42.5%成功数学对照 | 327.68–367.46 | −122.32至−82.54 |

忽略出售及保存延迟、每轮平均2.5次挥杆和完整6秒判定时，一组时间约202.5秒；高手较早按键会更快。450/15对应每机会30金币，盈亏平衡成功率约**52.05%–58.36%**。这个设计奖励认真操作，但**不保证盈利**，盲按可亏损；每次都绿是技能上界，不是“平均玩家每次都能中”。同一个玩家重复购买限次组可以持续主动游玩，不应把一次15的限制宣传成每日总收益上限。

抽鱼成功奖鱼与消费次数必须有持久化事件身份；按键随机判定结果在结算前固定，重开、重复按键或保存未知回执不可重抽或重新收费。失败不扣普通饵、不改变普通保底。界面展示剩余次数、每组售价和四色规则，只有该模式已聚焦且判定条有效时接收按键；不做全局监听，避免用户打字或使用其他软件时误收杆。

## 删除升级后的迁移与技术债

数值升级和升级按钮在第一版移除，但旧版本存档的rodLevel不能直接删除后判错，也不能丢弃已购买资产。迁移需要留存原等级/购买历史并明确补偿方案；历史可能是旧实际花费与后来改价不一致，不能仅按当前目录价擅自计算“原价退款”。升级折扣渡口代币在第一版暂缓掉落与激活；它在当前交付版尚未实施，不能伪称已有玩家持有。若未来遇到含该字段的合法兼容档，应保留来源记录并明确提示待处理，不在本版擅改用途或丢弃。此前每新道具0.2%要求和移除代币的概率归还鱼权重需主方案另列待批，不能自动增加另一个未讨论道具。本角色正式第一版候选暂缓未实现的渡口代币掉落，把其20/10000归还鱼：鱼率97.4%、道具直售贡献0.233；旧12区普通成功毛范围47.13–51.91，无饵47.13–50.01。该候选不再宣称仍然五新物，也不把代币自动改成其他功能。结果文件另存此前含五新物的历史未实施对照（97.2%、0.283，普通毛47.08–51.85），不能混用为第一版主结果。

不得让“删升级”只删UI而后台继续读rodLevel速度/品质奖励。规则、配置、存档校验和历史兼容读法应拆清；第一版固定普通竿、特殊许可独立计数、外观竿保持纯美术。测试应覆盖旧等级最高档迁移后实际节奏与普通品质和新档一致，同时资产凭据还在。
