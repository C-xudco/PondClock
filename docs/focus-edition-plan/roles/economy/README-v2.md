小时公式：`手动=3600/(90+2)×G`、`自动=3600/(90+20)×p×G`；90秒平均等待、2秒响应是示例，G为成功捕获毛均。G=50时手动1956.52，20／30／40%自动327.27／490.91／654.55，属于目标示意，不是新掉率当前模型实得。30%自动同时间价值约为及时手动25.09%。混合公式`3600×G×(0.3+0.7q)/(110-18q)`，q为及时手动鱼讯比例。

自动仅进鱼篓，不自动卖鱼或铸币；停止／关闭／睡眠不补鱼。小时估算忽略出售、保存延迟、旅行和停顿。满168真实小时任何鱼仍1金币。
