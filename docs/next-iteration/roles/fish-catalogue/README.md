## 两条互相独立的证据轴

| 证据 | 能支持什么 | 不能支持什么 |
| --- | --- | --- |
| 源A | 快照含游钓用途标签 | 当地普通竿钓、主动吞钩、具体地标存在 |
| 源B | 数据库有钩线记录，可能是商业方式 | 普通休闲竿钓有效或现实可钓 |
| 源C | 区域补充，名称/生态与钓获证据强弱分开保留 | 自动提升成A类或已验证钓法 |
| R1（10条） | 原始研究在指定水系/海区的逐种记录 | 2026年实时数量或地标定点分布 |
| R2（2条） | 官方土著鱼材料或水系适宜性表 | 实测捕获、场景点位或丰度 |
| R3（8条） | 只有快照线索、历史记录或分类未决 | 可立即上线的区域分布 |

CSV的`supported_region_ids`只填本轮有证据的大区；`potential_region_ids_unverified`仅是后续查证方向。
空单元格表示未查实，不用全国分布、H代表地点或同科相似鱼补齐十二个区。
本轮不制作实地钓法攻略；钓法字段只说明证据是否存在，不复制饵、钩组或操作方法。

## 现有42条逐项对照的主要缺陷

CSV逐条保留所有现有ID，JSON给出42条对照结果：23条可按名称意向定位源条目、17条无确定对应、2条明显物种未决。
“23条可对应”仅是编辑意向，现有FISH没有学名字段，不能宣称已确立正式分类或通过地区分布审核。
“17条无对应”不是删除建议：源文件并非中国淡水鱼完整名录，鳊、鲮、长吻鮠及多种地方特有鱼均可能漏收。
花鲈、罗非鱼是两条显著未决：前者不能直接换成F0735日本真鲈，后者不能把多个罗非类/杂交型当同一种。
白条按䱗F1551作意向，不以“白条”子串命中海鱼；鲶鱼按土鲇F1398，不合并全部鲇类。
现有鲫/金鱼不拆成新种；源F0386银鲫、F2692日本白鲫本轮均不新增，避免既有“鲫鱼”身份未明时重复计数。
黄颡鱼F2689与光泽/瓦氏分种；红鳍原鲌、蒙古鲌、翘嘴鲌F2696分种；旧属名只作对照，不另新增。
白斑狗鱼F0574与黑斑狗鱼F0577分种；东北当前白斑狗鱼是否合适须另核，不能偷偷改ID或替换存档。
哲罗鲑意向Hucho taimen而非H.hucho；日本鳗鲡与花鳗鲡已有独立ID；唇䱻不是花䱻。
“纳木错裸鲤／高原裸鲤／新疆大头鱼”等地点俗名要补正式身份，不能把地点名当物种有效性证明。
保护/珍稀展示的处理只标后续产品审核，不在本轮推导现实垂钓许可或作法律结论。
