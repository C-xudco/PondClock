# 对白与鱼讯声音实现

日期：2026-10-25；批准基线：a270e84，用户“开始迭代吧”。负责人 Leader。历史策划见 creative/README.md，实施资产不使用对白 RNG。

## 输入与意图

十秒五点保留；分三级轻微毒舌、45 秒安静复位；真实到达后随机介绍景观或当前鱼池。鱼咬钩使用本地短咕咚声，可静音、调音量和选择后台提示。

## 输出与文件

- `src/config/dialogue.js`：窗口、历史、冷却、情绪、权重及优先级。
- `src/data/dialogueCatalog.js`：通用每事件至少 8 句、12 区各 4 句，以及鱼种到达模板。
- `src/lib/dialogueDirector.js`：每个游戏独立的加权随机袋；最近全局 8/同事件 3 排除，耗尽逐步放宽但不紧邻重复。单句无可替代时静默。
- `src/services/biteAudio.js`：新鲜 bite token 一次播放；关闭/过期/后台禁用不会进入补播队列；自动播放失败只提示一次，不阻塞交易。
- `src/assets/audio/bite-plop.wav`：原创程序合成 320ms、16kHz 单声道 16bit PCM，10,284 字节，峰值 0.626。由 `scripts/generate-bite-audio.cjs` 确定性重建，不含外部采样。
- `useFishingGame.js` 由 Leader 独占接线；有效到达先持久消费水位再说，读档/导入只消费旧事件不补播；前台恢复不补旧鱼讯。

## 依赖与决定

交易模块提供 CATCH 捕获序号及 arrivalEvent/CONSUME_ARRIVAL。对白仅使用已入池的当前区域鱼名，不播未批准候选鱼。雨雪状态由独立天气模块负责；对白没有声称模拟天气是真实观测。

音频默认启用、35%、后台启用；设置存于 schema2。第一次用户手势尝试解锁播放；拒绝后可在设置主动开启。声音没有公网依赖。

## 验证与未测

`node --test tests/dialogue-audio.test.js` 初次 5/5 通过：语料覆盖/随机袋、三级点击及复位、到达鱼种、一次音频/静音/后台/过期、自动播放失败与手势恢复。实际声音听感、生产 UI 对白、后台真实系统音频尚待集成验收；不能把 mock 当作实机听感。
