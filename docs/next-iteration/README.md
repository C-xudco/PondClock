## 3. 需要你审核的数值表

所有金额为游戏内金币。下列概率是策划建议，未写入游戏配置。

### 3.1 成功收竿的排他掉落

| 结果 | 权重/10000 | 概率 |
| --- | ---: | ---: |
| 当地区鱼 | 9820 | 98.2% |
| 破鞋，卖1 | 150 | 1.5% |
| 泡水手表，未修卖50 | 20 | 0.2% |
| 网红修炼秘籍 | 10 | 0.1% |

建议非鱼不耗高级饵、不推进或重置鱼类高品质保底、不进鱼图鉴；仍完成本次等待与收竿。以上也是待审规则。

### 3.2 一次已付费修理（500金币）的结果

| 结果 | 权重/1000 | 概率 | 结果固定后可售价 |
| --- | ---: | ---: | --- |
| 失败 | 400 | 40% | 0（残值提案） |
| 普通机械表 | 550 | 55% | 10–200，含端点均匀整数 |
| 名贵机械表 | 49 | 4.9% | 1000–9999，含端点均匀整数 |
| 顶级机械表 | 1 | 0.1% | 恰好10000 |

10000只由顶级分支产生，确保**每次已付500的修理，P(售价恰10000)=1/1000**；不是“名贵分支内部千分之一”，也不是“每1000次修理保证出一块”。

按上述区间与残值，修理后物品毛均价337.2255，扣500后净期望−162.7745；相对直接卖50，增量期望−212.7745。修理是可能亏损的趣味选择，不是固定赚钱方式；改变权重或区间分布必须重算。

### 3.3 秘籍的推荐边界

- 使用前的鱼不符合资格；按已保存捕获序号识别“使用后”，不用可能相同/回拨的时间戳猜。
- 使用后捕获、出售时仍新鲜的鱼，按成交顺序最多3条获得 `Math.round(原地区售价×1.5)`；原地区售价已包含原有品质和重量，不把品质降为common。
- 过期、旧鱼、物品不加成也不耗次数；七天到期仍1金币。**过期是否耗次数是我们补充的待审解释**，若你要严格按前三条后捕获已售鱼计数，也可改为过期占名额但售价仍1。
- 批卖按catchSequence、uid稳定排序，逐鱼计算后求和，与同顺序单卖一致；第4条不加成。原价3的两条符合鱼分别5，共10，不先合价再乘成9。
- 有剩余次数时不消耗第二本，不叠加或覆盖；用尽后才可使用新本。金币、鱼移除和剩余次数同一笔保存。
