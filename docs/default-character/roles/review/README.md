## 可判定目标

- 免费 `minimal` 稳定ID、旧档与购买权益不变，外观变更不影响鱼获随机/鱼竿等级/价格/天气来源。
- 新人物晴/雨PNG有真实透明alpha、角落透明、足够可见内容；不能把白背景或图像已载入当作透明正确。
- 每次只有一个默认人物资源；背景与人物的位图分别统计。旧版“默认无任何image”断言本轮已过时，历史报告保留。
- 图像手锚点与握竿位置、支持点与场景地面一致；两主题、十二地区和完整咬钩姿势都检查。SVG杆线连续性与PNG是否烘焙鱼竿分别说明，后者需目视素材。
- 雨天换防雨形象，雪覆盖只落在人物支撑路径上；阴雨雪无多余太阳。人物点击区域和对白不出框，两档客户端尺寸仍可用。
