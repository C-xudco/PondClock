# 1.1.1 IP与天气修复验收

2026-10-21，Asia/Shanghai。用户反馈朋友完整ZIP显示“离线模拟”，IP似乎不能更新。该旧文案来自天气链路，不能单独证明定位失败；朋友具体HTTP错误尚未提供，不能把本机结果当朋友机器实测。

## 发现与修复

- 原实现仅有ipapi，先前用户批准的真实请求返回403。增加固定HTTPS备用IPWhois；403、超时、无效响应、未知中国省份改试备用，记住本次运行最近成功服务。合法境外结果不编造成国内水域。
- 系统代理变化可能仍复用旧连接。定位使用独立内存session，每次识别重载代理并清理该session连接；不修改系统代理，不中断天气session。HTTPS、禁止重定向、无凭据、白名单、响应上限和超时保持。
- 天气原来吞掉全部错误并等待15分钟；同坐标重识别IP不能恢复天气。现在显示独立来源、错误、更新时间、重试时间，支持手动、online、focus、可见轮询。普通失败60秒起指数退避，成功15分钟缓存，缓存最多6小时，关闭联网后也会本地过期为模拟且清空温度。
- IP与天气分别显示；模拟晴雨不再称“离线模拟”。没有IP坐标使用现实记录地区或家乡代表点，标“参考城市”；游戏买票不移动这个参考点。位置缓存与本次IP有明确区别。
- 设置提供只读可复制诊断。选择性序列化版本、服务、安全错误码、时间；不包含IP、位置、响应正文、代理凭据、路径或存档。
- 429按供应商分别等待，全部受限才全局等待最早恢复时间。HTTP429和HTTP200中已知配额错误均在main建门禁，renderer重建不能绕过；手动、online与切地点不绕过服务等待时间。

## 协作与证据范围

Leader负责端点配置、主进程代理、界面、诊断、构建和发布；startup_audit负责定位故障切换与16项测试；installer_fix负责天气控制器、hook与21项测试；repair_supervisor独立只读审查并发现“离线缓存永不过期”和“HTTP200配额不受main门禁”两项，均补修及回归。数值集中在services配置，固定端点由renderer/main共享白名单。

自动规则/故障注入与界面mock不能代替真实网络；真实开发Electron请求也不能代替朋友机器和真实VPN切换。最终检查状态见本文件末尾、[发行资源](RELEASE_CHECK.json) 和 [本次真实网络](NETWORK_1.1.1_CHECK.json)。

用户在本轮明确批准一次备用定位和返回坐标的天气检测。通过与产品相同的Electron Chromium网络栈、白名单、独立定位session和解析器，IPWhois成功约1045ms、有效省区映射与坐标均通过；Open-Meteo成功约1363ms。结果只留服务、成功/错误码和耗时，不保存完整IP或位置。诊断进程显式禁沙箱，未将它冒充最终普通EXE整链联网实测；未切真实VPN。

本轮真实UI诊断使用实际main和生产bundle、独立profile，模拟主服务403→备用成功；天气失败不影响IP免费解锁；同坐标天气独立恢复；两家定位失败标缓存、天气仍可联网；诊断文本不含坐标和路径。共14组，最终以NETWORK_UI_CHECK.json哈希对应版本为准。它是显式禁沙箱诊断，真实HTTP被阻断。

关闭联网会停止新增请求并丢弃晚响应；已交给主进程的HTTP可能继续到8秒截止。renderer取消不通过IPC立即中止在途天气，这是当前明确边界，不宣称立即收回已发送网络流量。旧安装器迁移/卸载问题仍未关闭，本次主交付完整ZIP。

## 朋友复验

1. 退出旧程序，完整解压`PondClock-1.1.1-x64.zip`到新目录，打开里面的PondClock.exe，设置确认版本1.1.1。
2. 开启“联网识别所在地与天气”，点“立即识别所在地”。看“IP地区”是否本次成功，而非只看右上角天气。
3. 点独立“刷新天气”；若限流，等界面时间。无IP坐标时参考城市不等于本人所在地。
4. 换网络/VPN后切回窗口，再看本次IP来源与时间；免费解锁保留，金币与游戏位置保持。
5. 若失败，展开“查看联网诊断”，复制文字反馈。无须发送IP、存档或代理凭据。

朋友的网络可达性、真实VPN切换与旧安装器升级仍为未完成实机验收，不承诺所有免费服务在所有网络可用。
