## 4. 两种优惠的统一生命周期

建议待用状态分为两个独立槽，暂用名称 ticket10 与 rodUpgrade10；实际字段名由架构角色统一。每槽为null或含sourceItemUid、固定sourceItemType、ruleVersion的待用凭据。两类可以同时待用，但一笔付款只适用其对应种类。

### 激活：先消耗物品，保存一个待用权益

1. 玩家点击“下一张机票9折”或“下一次鱼竿升级9折”，不是拾取时自动激活。
2. 检查地面状态、uid仍在、类型正确、同类槽为空；渡口代币还须存在下一档数值鱼竿。
3. 合法时，**同一笔保存**移除该uid并建立待用权益；确认后才显示“已激活”。这时物品已使用，优惠仍完整待用，不是立即完成了票或竿的购买。
4. 同类已有待用优惠时，第二件不能使用：按钮解释“已有一次待用优惠，先用完”；命令也拒绝，第二件留在库存，不扣钱、不刷新或覆盖第一张。
5. 两个待用权益不能共用同一个sourceItemUid；待用来源uid不能同时留在items。该约束应由schema与纯规则共同验证，不能只靠UI或最近128条命令。
6. 没有时间到期。离线、重启、旅行、天气/网络改变不刷新也不丢失权益；不支持同类叠成81折、数量累计或反复激活。

### 付款：成功时才消耗待用权益

下一次有效的对应付费命令自动用券；玩家不需要再点一次，也不新增“取消优惠换现金”。

- 付款检查用**折后实付价**；例如余额540可以用券升级原价600的鱼竿，不能仍按原价判余额不足。
- 扣实付金币、建立已付航程或提升一档数值鱼竿、清除对应待用权益，在同一笔状态变化和原子保存中完成。
- 其他待用槽不动。买机票不吃竿券，升竿不吃机票券；外观商城、换皮肤、买饵均不适用。
- 查看报价/打开面板不消费；余额不足、非法目的地、同地无航段、飞行中、无可升级竿等失败请求也不消费待用权益。
- 明确未提交的保存失败保持旧状态。**回执未知不能直接认定失败**：按原命令ID重读确认，既不能再付款一次，也不能自行补回优惠。已落盘的成功付款不能因为消息丢失再赠券。
- 使用/出售同件物品并发，由现有串行队列决定先后，后一个不能再处理已移除uid。源uid终态和待用凭据保持一次性，不用扩大历史数组冒充去重。

飞行中所有主动拾物按钮统一禁用（出售、补饵、激活优惠），库存和静态描述仍可看。飞行中已存在的另一类待用权益原样保留。

## 5. 具体9折与边界

### 统一取整

建议折后实付为正数整数四舍五入：

- 语义：Math.round(basePrice × 9 / 10)。
- 受控整数实现等价式：floor((basePrice × 9 + 5) / 10)。
- 优惠金额=原价−实付；UI、预览和实际付款共用相同报价函数，不分别“先四舍五入折扣再相减”。
- 当前价格范围相乘安全；配置入口应验证正整数/安全整数范围，未知或负价格不默许成交。

### 指南针：一张任意有效游戏机票

对所有合法起点/终点航段都可用一次，不限近远和是否已解锁。当前原价200–6000，折后180–5400，省20–600；**不加金额上限，也不减飞行时长**。

假设标准票价2000，显示“原价2000 · 待用9折 · 实付1800”，成功起飞保存farePaid=1800。报价至少保留折前票价、实付、优惠规则版本和来源凭据；已付航程/退出后抵达只按保存的绝对到达时间继续，不重新计费。

REAL_VISIT的“在现实所在地免费垂钓”、IP自动解锁、到达动作不是购买机票，均不消费待用机票优惠。目的地等于当前地区或无效ID时不扣钱/不吞券。没有新增退票或取消航程功能，不暗加退款规则。

### 渡口代币：下一次数值鱼竿升级

| 从当前等级升级 | 原价 | 9折实付 | 节省 |
| --- | ---: | ---: | ---: |
| 0级竹竿→1级玻璃钢竿 | 600 | 540 | 60 |
| 1级玻璃钢竿→2级碳素竿 | 2600 | 2340 | 260 |
| 2级碳素竿→3级大师手工竿 | 9000 | 8100 | 900 |

0级基础竹竿当前成本0，**不是一次可购买的升级**；代币作用于下一档600升级，不用于“买一根0价竿”来清券。满级没有下一档，激活代币应拒绝并保留物品，玩家仍可按建议25直接卖出。

已存在但暂时无可升级目标的待用权益（例如导入或未来规则变化产生的兼容状态）不能在载入时静默删除，显示“暂无可用升级”。合法BUY_ROD只升一档；更好的判定窗口/品质等是原本该等级装备的规则，优惠本身不额外增能力。

竿外观、商城水墨包、人物皮肤与装备外观切换均不算数值竿升级，不使用这张券。

## 6. 密封饵盒与通用库存

饵盒保留v1简单功能：地面使用时，移除uid与baitCount+1同笔保存；+1份仍对应当前5次鱼类捕获，不是立即送5条鱼，不刷新或覆盖当前baitLeft。每盒只能用或卖一次；安全整数越界、类型错误、uid不存在、飞行或保存未提交都不吞盒。没有新时间buff。

五种新道具均不设置七天失效，建议卖价不随地区/品质/重量/秘籍变化；七天固定1只继续用于鱼。它们不进入鱼类图鉴，不另建收藏册。初始100金币、原2份鱼饵不因升级再发一次。
