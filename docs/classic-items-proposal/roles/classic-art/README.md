文件所有权仅限本目录。没有修改 `src`、`desktop`、package、测试、产品脚本、版本、存档或发行包；没有运行旧/新EXE、没有启动GUI、没有联网。原始文件副本、JSON证据与静态预览都保存在文档目录，不是已接入产品。

## 审批后建议怎么适配

### 默认与人物包

1. 免费 `character='minimal'` 恢复**真实1.1.1轮廓**。不能只退回1.3.0的 `Silhouette`，那份形状、脚位、竿和位置已经不相同。
2. 白发晴/雨PNG保留为独立可选角色，建议新稳定ID `whitecape`，商品建议ID `whitecape_character_pack`。名称与金币价由Leader主方案列为待审；只授予人物槽，不能捆绑覆盖玩家背景或鱼竿。
3. 既有免费 `minimal` 存档一律恢复经典默认；不把 `gameVersion='1.3.1'` 或曾加载过候选当作“已购买白发”的证据，也不强制把旧minimal改成whitecape以保留突兀风格。
4. 白发是否首期免费领取、是否赠送候选用户、或按金币购买，是**单独待审的权益政策**。如采用赠送，记录真实grant来源，不能伪造付费扣款凭据。水墨、云游/暮色旅人和竿的已购权益一项不删。
5. 新ID及新增道具需要什么存档版本，由存档负责人统一设计一次迁移；不以“只是美术”跳过目录/所有权兼容检查。旧版本不认识新商品时应明确版本保护，不悄悄丢字段。

### 原版几何不能直接套现在的常量

| 量 | 真正1.1.1经典小人 | 当前1.3结构 |
| --- | --- | --- |
| 身体/脚底基准 | `(866,246)`，整体scale `1.1` | 共享支持参考约`(940,329)`，再加地区offset |
| 原始握竿点 | `(832,203)` | 普通皮肤`(853,244)`；白发候选另有握点 |
| 原始竿尖 | `(575,128)`，还要经历竿旋转、人物旋转、整体scale | 现有helper基于另一组身体/握点 |
| 气泡 | left64/right2.5/bottom77%，tail62%，maxHeight20% | 当前按另一人物范围和地区偏移计算 |

适配时引入**角色几何档案**，不要全局把 `FISHER` 常量换回1.1.1，否则会拖坏水墨/白发/其他付费人物。

- 简洁背景中优先保持经典原始位置与比例，重现截图的留白和低存在感。原版1000×440画布、岸线、浮漂常量都能从Git恢复验证。
- 在水墨背景中只做明确、等比的角色锚点对齐，再叠加该水域的既有offset，确保脚在原有岩岸。不要非等比拉宽小人，也不把人物轮廓当新的水岸蒙版。
- 统一矩阵依次包含角色自身原始scale、人物前倾、地区摆放；竿尖/钓线端点/握点/点击区域/气泡都消费同一档案。原版 `fisherTipAt` 已包含scale，不能再重复放大一次。
- 默认朴素竿恢复原版有粗细变化的竹竿轮廓、导环与绕线轮；使用青玉/晨光竿时只从对应外观配置取颜色和细节，不能重绘第二根竿或第二条线。鱼竿等级和能力不因外观回退。
- 原版固定SVG ID改为实例唯一ID，防止商城预览与场景同屏时渐变/滤镜串用；保留原始形状与微弱轮廓光，不恢复历史全局ID冲突。

### 天气适配

斗笠和长衫的安静剪影是晴天默认。雨天可在同一旧轮廓里加低对比短蓑衣/披雨层，避免变回明亮大体积人物；雪天只在斗笠上沿与肩部支撑点逐渐积雪、转晴消融。新增雨具线条和雪支撑需要与原版轮廓对齐，单独预览审批。

天空、日月、水面、雨雪、实际所在地/钓点/手动模式沿用现行系统；仅恢复人物不得重新引入旧版“下雨仍固定亮日轮”等历史表现。未知天气仍按来源标记，不让人物美术改写真实观测。

## 可判定验收清单（尚未执行）

1. 对照真实1.1.1，默认斗笠、长衫、细肢、腰鱼篓、原始竿轮廓能逐项对应；不是另一个简化剪影。
2. 420×350与640×490的默认画面保留原版安静比例和位置；深浅背景可辨，没有新增大块光晕或白底。
3. 两场景、12水域、待机/咬钩连续姿态：脚落岸、手握竿、线起点与竿尖连续，浮漂仍在水面，气泡和点击范围与人物一致。
4. 同时只有一个人物、一根竿、一条钓线；默认/白发/水墨/其他已购皮肤切换与独立竿混搭正常。
5. 雨具/帽肩积雪与当前天气视觉状态一致；真实/钓点/手动展示和顶部所在地独立，旧日月bug不回流。
6. 旧minimal恢复经典，已购水墨/其他皮肤和金币不变；白发新包只按用户批准的购买或赠送政策出现，反复载入/重复购买不重复扣款或授予。
7. 原档备份、失败保存、未来版本保护、离线重启与完整ZIP资源检验完成后，才生成可推荐的新小版本。
