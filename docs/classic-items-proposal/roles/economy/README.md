# 平均每竿约50金币：数值候选与复算

## 职责与口径

本角色独占此目录，只读取真实`catchOutcome`、鱼/竿/饵配置、市场、重量舍入和保底规则，输出独立数学模型、候选配置和CSV。不写`src/desktop/scripts/tests/package/release`。

收益口径：成功收竿后的鱼在**捕获当地立即出售、仍新鲜**，拾物按可直接卖价计入；泡水表卖50，秘籍不能卖按0。未包含漏鱼、鱼饵/升级/机票成本、跨区套利、秘籍+50%、修表赌博和优惠券节省。券减少支出，不是钓到的现金。

新五物各20/10000，卖价3、8、25、30、18，合计直卖毛贡献`0.168`金币/成功竿。旧鞋/表贡献`0.115`，总非鱼直卖`0.283`。新表鱼率0.972，所以 **E成功竿毛=0.972×E条件鱼当地卖价+0.283**。现行旧表对比采用真实`0.982×E鱼+0.115`，没有把新物贡献偷偷加进旧表。

“45–55”是本角色建议的**工程验收容差**，不是用户另行指定的上下限；长期均值靠近50，临时保底条件、单条名贵鱼仍可高于55。

## 为什么推荐同时微调价格和品质

仅提高史诗、传说出现率可以在数学上抬收入，但低价区会需要过多高品级鱼，削弱稀有感；本角色没有证明“只调爆率绝对无解”，也不以绝对无解作理由强迫改价。

推荐更可控的组合是：**便宜鱼基础价上调，高价鱼不降；品质维持普通占多数、传说稀少；按地区调稀有档权重**。不改50种鱼的ID、栖息鱼池、区域鱼种抽取权重、体重/体长、品质卖价倍率、地区稀缺系数和七天规则。

### 品质候选——与价格成套复核

每种鱼原品质基础权重先统一乘4，稀有档再乘下表地区系数；然后仍按现有代码加鱼竿/鱼饵的绝对权重，最后在保底状态将史诗/传说权重乘5。

`w(q)=oldSpeciesWeight(q)×4×(q是稀有 ? 地区系数 : 1)+bonus×oldBonusRate(q)`

`bonus=鱼竿0/3/6/10 + 有效高级饵6 + 最佳点击0`。保留30条非高品质鱼后的软保底倍率5。最佳点击目前加成为0，on/off行数包含重复值；没有宣称当前最佳点击给额外奖励。

## 明确代价与未决平衡

1. **装备品质收益被稀释。** 基础权重乘4后仍加原来的绝对bonus，相对提升变弱；候选基础竿无饵到顶竿有饵仅提高约2.48–4.62金币/成功竿。原鱼讯速度和判定窗口不变，但不能说品质收益原样。
2. **付费高级鱼饵的边际现金收益仍不好。** 现价120/5鱼，持续购买且每次鱼都消耗一份次数时，按0.972鱼率，每成功竿成本23.328；候选有饵状态毛收入扣此成本约24.82–31.24。相对同竿无饵，毛收入只增加约0.814–1.896，不能宣称为赚钱值得购买。是否调整鱼饵价格/用途应另列待批，本候选没有擅自改120或5次。
3. **旧库存升值。** 2400个“鱼种×地区×品质”单元中2256个体重均价改变。中等体重最大增加示例为淮河传说白条62→655（+593）；完整体重均价最大增加592.75，最大均价比约10.577。这里不是任意体重的全局绝对最大值。鱼过期后依旧每条1，不把它纳入50均值目标。
4. **保底阶段允许波峰。** 384个即时条件的候选期望约45.125–73.070，最高是暂时高品质放大状态；这不等于长期平均失衡。单鱼还可能更贵，没有按50或55裁剪鱼价。
5. **不覆盖所有操作策略。** 跨区卖鱼、秘籍加成、修表中奖、攒过期鱼、漏鱼都会使结果不同。新券9折减少的是相应下一次支出，不能加进本地直卖现金期望。

重量按游戏实际的“均匀抽样后保留两位小数”枚举每个0.01区间，包括端点半格；以真实重量分布积分，不拿中等体重替代期望。价格模型重建当前稀缺系数和整数舍入，2400个原始中重报价与真实`quoteFish`逐项一致。

保底采用再生周期公式：正常30状态访问质量和`Σ(k=0..29)(1−h0)^k`，保底尾阶段`(1−h0)^30/h1`。先求鱼序列稳态再乘鱼率；非鱼是与保底状态无关的自环，不改变该稳态比例。不是把“保底状态”与普通状态各占一半，也没有用几十次随机试钓估计均值。

这是连续均匀模型下依照游戏舍入的浮点计算，忽略很小的32位随机数离散误差；0.001金币之后的数字不应当作实玩收益承诺。持续有饵是固定对照场景，不代表初始2份免费饵永不耗尽。
