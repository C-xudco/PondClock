## 六物功能与概率复核

建议六物：锈铁罐、河蚌壳、渡口代币、密封饵盒、漂流瓶、磨花指南针。新增权重共400/10000，鱼从9820变9420；旧破鞋150、手表20、秘籍10的绝对概率不变。总物品580/10000=5.8%，不是在旧1.8%内再分给六物。

独立复算结果见JSON：新物全部出售增加0.648金币/成功收竿，同时替代4个百分点鱼。若原条件鱼平均实际卖价为F，则仅这两项的现金差是`0.648−0.04F`，平衡点F=16.2；不能概括为所有区域都增收。鱼的出现率相对减少约4.0733%，品质/市场/保鲜算法本身不改。

饵盒卖30或换库存高级饵1份。店价120是替代采购机会价值，不是发120现金；选择使用会放弃30的卖价。一次补1份现有5次饵，不能补满`baitLeft`或把一份误写为单次饵。低价收藏可长期留库存；瓶/指南针只读，不给金币、解锁、鱼饵或buff，不消耗次数、不给重复领取奖励。

漂流瓶的固定`noteId`/`noteVersion`应在掉落时确定并经schema4显式校验，与`originRegionId`对应；不在每次打开时抽新资产/改成当前地区，也不冒称实时天气。指南针只从同一`quoteRoute`目录查当前落地起点的最便宜三条，按价格、飞行时长、目的地稳定ID依次排序；飞行中暂不可查是本轮工程默认。它不免票、不解锁、不改132航段的报价或时间。为沿用统一入口，瓶子的主动阅读按钮也在飞行中禁用，物品静态说明仍可看。

等待时间换算仅是“基础竿、均值90秒、每次立即成功收竿”的算术示例，不是用户实测。新增任意一物平均25次成功收竿约37.5分钟，但不是保底；单一新品可能需100–333次。应在审批时接受或调整这一节奏。
