## 玩法接线

普通开始后按保存的等待截止时间开放20秒鱼讯。点击只处理当前 `attemptId` 且必须在窗口内；未点到期提交一次自动结算，成功率由域配置30%。普通饵默认关闭，可主动选择；物品捕获和失败不消耗饵。停止不补结之前的鱼讯。超过10秒没有正常调度，或首次遇到早已超过20秒的等待事件，提交 `RECOVER_RUNTIME`，不回放离线收益。

主动抛竿先进入主动模式再开始一轮；每次挥杆3秒，域决定本轮2或3次挥杆后进入收鱼条。只有进入条时扣1次，空挥不扣。条显示白0%、红10%、黄50%、绿100%，6秒超时，取消与失败都不退已扣次数。按钮和按键均只发送停针命令，位置和随机结果在可信计时/域中求值。退出前或重新打开后，未完成条保持同一尝试并暂停。

专注标题不能为空、最长60字；一次一个25分钟计划，完成后奖励1包高级饵并提供5分钟休息。可提前结束休息开始下一轮；取消/未完成不奖励。每天完成4轮奖励1张免费单程通票、每天一次且可积存。归属日固定为开始该计划时的电脑本地日期；跨午夜不把该轮挪到第二天。计划计时表示应用内计时，不监测用户实际做了什么。停止钓鱼和飞行不会阻止专注。

## 焦点、休眠和声音

主动条出现或恢复时，只在游戏本来已获得焦点且没有面板遮挡时聚焦条内部；不把游戏从其他应用前抢到前台。键盘过滤重复按键、输入法组合、Ctrl/Alt/Meta组合、系统/导航键和编辑框；外部按钮/链接也不会误收鱼。Esc在有效主动条内表示放弃。打开面板时，条的键盘处理阻断。

窗口失焦或隐藏只暂停正在运行的主动条，普通自动钓鱼与专注仍可继续；电脑休眠、页面离开或应用退出则先同步冻结可信计时，再提交最后计时和恢复命令。恢复后普通钓鱼停止，专注及主动条需继续操作，不把关闭/休眠时间记入专注。退出消息处理完后向桌面端发送确认；桌面端还有独立退出等待与保存队列处理，须由原生验收确认。

已有离线鱼讯声、音量及后台声音开关保留。专注期间减少普通捕获的对白/弹出提示；鱼获仍保存。导入时暂停调度，导入后重新载入并复位结果通知、水域到达水位、专注奖励计数，避免把历史奖励再提示为新奖励。

## 接口约定

Hook提供 `fishing/activePass/focus/discounts/freeTravelTickets` 保存字段及 `focusView/activeBar/activePhase/activeRemaining` 显示字段。操作包括 `startFishing/stopFishing/setFishingBait/startActiveFishing/castActive/resumeActiveFishing/pauseActiveFishing/stopActiveBar/cancelActiveAttempt/buyActivePass/startFocus/pauseFocus/resumeFocus/cancelFocus`。旅行支付继续通过 `travelTo(toId,payment)`，支付与九折复用域报价；不能在UI中复制价格公式。

6. 依据保存的挥杆截止推进，暂停条不计时。
7. 停止/旅行状态没有虚构鱼讯倒计时。
8. 真实会话与调度器组合可完成无人点击结算，长中断不补鱼。
9. 真实主动流程进条只扣1次，绿区停针保存1条鱼。

这些测试包含确定性调度器和真实会话组合，不是实际Windows焦点、键盘输入法、音频设备、休眠或安装器实测。对应原生实测应由发行验收记录另列。
