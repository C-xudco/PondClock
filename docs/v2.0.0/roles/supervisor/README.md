## 发现与整改

1. **旧档未来封装选择错误（已修复并独立复测）**：旧目录若同时有 `envelopeVersion=2/schema3` 与旧封装合法槽，复制助手曾把未来封装当普通坏槽，继而选择较旧进度。Leader 已加入未来封装显式阻断。回归要求停止自动导入且两槽原字节保留。
2. **计时命令重放吞掉新时间（已修复并独立复测）**：一条已提交 `FOCUS_TICK` 在五秒后重试，域曾正确返回原状态，但会话仍扣除这五秒可信计时额度；下一新检查点无法追回。`TICK_ACTIVE` 同样出现。域实现者已在串行命令队列内提前返回已提交命令，保留新额度。两项回归均由稳定失败变为通过。
3. **收鱼可操作性（交 Leader 实机验证）**：原 `game.busy` 同时包含后台计时检查点，写入较慢时可能暂时挡住主动条按键及普通鱼讯收竿；主动指针原由250毫秒主循环更新，视觉为跳步。已建议后台计时与用户操作互不阻塞，普通收鱼沿用内部防重标记和串行队列，指针使用局部平滑投影且命中继续信任会话时钟。此项不能由纯域单测视作已验收。

## 可读规则与保留边界

普通无人收鱼采用每次有效鱼讯一次30%判断；重开、休眠或长时间无调度不补离线鱼获。番茄25分钟完成奖励一包高级饵，4个计划为当天100分钟并奖励一张单程自由行通票；计划归属开始当天。计时信任本应用观察到的单调时钟，不判断用户是否实际工作。调度缺口超过10秒会保守暂停／恢复运行状态，不补算缺口；系统休眠通过桌面生命周期先冻结再保存。

主动竿在第2或第3次挥杆进入进度条时扣一次，空挥不扣；取消与超时不退款，重开保留已付事件并暂停，手动继续。键盘监听只在本应用已有焦点时接受输入，忽略输入框、IME、按键重复及系统组合键，没有全局键盘钩子。

源码与自动回归不能替代打包版的可见窗口、缩放布局、输入焦点、退出保存、安装与卸载验收；这些由 Leader 另记实际执行证据。当前审查不证明所有真实网络出口均可取得IP或天气。
