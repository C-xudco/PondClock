## 航线和市场规则

有向图覆盖每个不同起终点，无自环。Haversine距离统一映射：最短60秒、最长180秒，其余按比例；基础机票200–6000金币、10金币档取整。反向同距离因此当前同价同时长，数据仍以有向航段表示，不把每个目的地写成固定票价。扩大到17地后最短/最长距离基准会影响旧航段；已支付旅途的价格、起飞和到达时间继续使用存档原值。

当地鱼池产出比例决定0.8–2倍市场稀缺系数；最高产地0.8、不产地2。鱼捕获满168真实小时固定1金币，不受品质、稀缺和秘籍抬价。旧鲜鱼使用新行情，但不重抽物种、品质、体型或捕获时间。

## 平衡结果与核算口径

口径是**一次成功普通收竿后，鲜鱼立即本地出售＋物品直接售价的平均毛收入**；不是每次挥杆最低收益，不含鱼饵、机票、主动竿成本，也不含修表、秘籍、跨区卖鱼、赠礼和优惠节省。鱼74%，全部非鱼直售期望合计4.57金币。

所有17地、普通有/无饵及长期保底分布的平均毛收入为 **47.4206–51.0594金币**；无饵为 **47.4206–49.3012金币**，符合约50目标的工程容差45–55。临时“正好进入保底”等条件均值为45.8558–62.5767，不将它误作长期平均或单竿上限。普通无人操作每次鱼讯仅30%成功，另须等待完整20秒，单位时间收益低于及时手动收竿。

主动品质乘数集中为普通1／稀有1.25／史诗4／传说5，不读取普通饵、普通保底和旧鱼竿等级。史诗从最初工程候选3.5改为4，是为了让淮河、白洋淀也通过逐品质优势比较。当前17地的主动稀有/史诗/传说占比均高于当地普通“有饵＋长期保底”对照。成功主动鱼获的本地直售均值 **61.6404–70.0297金币**；仍需扣购买机会成本及失败概率，不能将它宣传为每次保证收益。普通传说占比0.3193%–0.6771%，主动为0.5262%–1.2680%。

`src/config/balance.js`是品质规则唯一来源，旧鱼价通过集中公式调整；具体地区稀有因子也在该文件，不能在UI复制。物品权重在 `src/config/lootConfig.js`。
