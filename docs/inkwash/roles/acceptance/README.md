## 2. 证据类型不能互相替代

| 标记 | 能证明的范围 | 不能据此宣称 |
| --- | --- | --- |
| AUTO 自动断言 | 假时钟、固定seed、供应商夹具下的代码映射、状态隔离、几何、调度和数据不变式 | 已联网、实际生产UI已显示、美术好看或发行可运行 |
| ART 主观美术 | 人工对照两张参考，评人物墨阶／飞白、地域轮廓、构图、两尺寸可读性 | 动画时序、竞态或接口可用性通过 |
| FRAME 连续帧 | 同一输入下到达前→接触→扩散／消融结束的帧序列或短录像，附粒子ID／落点／hitTime | 单张涟漪图、源文件存在mask即证明联动 |
| PROD 生产UI | 实际生产bundle／桌面应用真实页面与合法测试输入的集成、布局和交互 | DEV专用`?weather=`／`?hour=`、静态临摹页或源代码镜像可代表生产入口 |
| TRANSPORT 桌面运输 | main层真实在途请求数、桥接Promise完成、超时／取消／429解析及冷却；故障可由受控运输夹具注入 | renderer mock次数就是HTTPS并发，AbortSignal即主进程已取消，受控响应即真实服务返回 |
| LIVE 真实网络 | 后续单独记录实际IP／天气提供者、请求时间、地点、状态、字段与回退 | mock、缓存、模拟、受控429可冒称真实联网已测；不刻意轰击服务制造429 |
| EXE 普通发行 | 最终普通EXE在正常安全选项、独立profile下启动／显示／退出，ZIP与ASAR资源完整 | 开发服务器、文件存在、exit 0或关闭沙箱的宿主诊断可替代普通EXE |

| 队列／风暴／优先级 | 冷缓存、重复IP／focus／online／手动／重连；记录队列、去重、实际启动、命中、重试、预算；header／scene优先，首次后台先于后台重试 | A09、A11／G05 |
| 缓存／晚响应 | A晚于已抵达B返回、IP连续变化、景点版本改变、查看器切换／关闭；只写仍有效身份的自身缓存，不覆盖当前选择器。现实与12区按地点独立 | A11／G03、G06 |
| 缓存损坏与时间 | v1四标签、缺字段、坏JSON、无效坐标、未来／回拨／过期、不可写storage；unknown／legacy／模拟诚实降级，不造温度或观测时间，不重置主档 | A11、A12／G06、G12 |

AUTO故障先用假时钟、deferred promise、独立storage复现；TRANSPORT另记main实际计数，不靠renderer等待者数量推定。

候选调度预算为并发≤2、启动间隔≥1秒、单轮≤13点、滚动15分钟≤26次／单点≤3次、15分钟新鲜／6小时缓存；这些尚未测试，最终冻结值见天气／架构契约。
真实LIVE后续单列： verified景点坐标／来源、隐去完整IP的请求日志、实收字段／单位／时间与UI标签；受控故障和自然服务返回分别列，未遇真实429不填已测。
数字坐标仍pending的地点不得试猜请求或冒称真实天气；正式十二区当地天气交付须全部verified。本轮不请求真实IP或天气。
