## 3. 纸感、墨色与文字 tokens

以下是与美术暖纸、五档墨阶一致的起始值，后续在实际两档窗口评审并测对比度；不能把候选色标成已通过色板。

| 语义 token／建议值 | 用途与约束 |
| --- | --- |
| `--ink-paper: #F2F0E8`／`--ink-paper-raised: #E7E8DE` | 阅读面与次级卡；关键文字下接近不透明纸底，透明外边缘仍留空 |
| `--ink-strong: #26332F`／`--ink-body: #435149`／`--ink-muted: #59635C` | 标题／正文／次要说明；淡墨仅作远景装饰，不能拿低透明度正文模拟远山 |
| `--ink-line: #858D80`／`--ink-line-soft: #B7BBAE` | 控件边界／非交互分隔；细墨线与轻微不规则边缘不能损害点击尺寸 |
| `--ink-accent: #3F6B65`／`--ink-gold: #856733`／`--ink-cinnabar: #9B452F` | 选择与焦点／收益或品质点色／错误及破坏性动作；状态必须同时有文字或图形 |
| `--ink-paper-grain-opacity: .02–.04` | 低对比纸纹起试；单层、pointer-events:none，不穿过透明外框、不用重噪点滤镜或固定白纸整屏铺底 |
| `--font-ui`／`--font-heading`／`--font-number` | 正文用系统中文黑体，短标题可用本地宋体回退；数字 tabular-nums。无联网字体，新字体包另报体积／许可 |
| `--text-body: 12–14px`／`--text-meta: 11–12px`／`--text-clock: 26–32px` | 小窗关键正文不低于 12px，来源／时间不低于 11px；通过换行与内滚动解决空间，禁止再降至 8–9px |

纸面圆角建议 8–12px、1px 墨线、浅灰柔影；不增加厚卷轴、印章堆叠或大面积仿旧污渍。正文行高约 1.45–1.6；按钮字不使用草书，鱼名／温度／票价／倒计时不竖排。
共享 shadcn `background/foreground/card/popover/primary/muted/border/input/ring/destructive` 对接上述语义；品质以 `quality.id` 映射普通墨灰、稀有青、史诗淡紫、传说赭金，不改 QUALITIES 的倍率／rank 或通用全局颜色类含义。
默认、hover、active、selected、focus-visible、disabled、busy、warning、error 各有样例：selected 用底色＋边线＋aria-pressed；焦点建议 2px 清晰实线；disabled 降装饰而保留文字可读性，并保留原禁用原因。
面板主按钮目标高度约 32–36px，窗口按钮目标不少于 24×24px；小窗优先留足命中区。普通文字目标对比度 4.5:1、焦点与重要边界 3:1，均为待测指标。

## 4. 地点、天气字段与顶部布局

按架构复用 `SceneSite`（place／address／verification）、`WeatherEntry`（targetKey／status／errorCode／retryAtMs）、`WeatherSnapshot`（temperatureC／source／quality／observedAtMs／fetchedAtMs）和 `WeatherVisualState`；`SceneDefinition` 只供场景定位。字段定义不在 UI 另立版本。
温度与原码标签取同一个 Snapshot／天气角色的文字 selector；VisualState 仅供图标类别或语义提示，UI 不由 rainGear 推断天气、不把 unknown 回退为晴天。所有地点文字按当前身份绑定，不能从上一次缓存标题取名。
现有 ClockPanel 的 `regionName` 来自游戏 currentRegion，不能与现实 weatherPlace 混排而暗示同一地点。建议 Leader 传明确 `headerPlace`／`headerEntry`，将游戏区信息移给场景标签；如顶部保留游戏区，必须另标“游戏水域”。这些是接线建议，不取代天气主契约。
顶部时间／日期继续按现有电脑时钟；天气区始终标“现实所在地”，IP 缓存和参考点分别写“历史 IP 地点”“参考地点”，不能因参考城市有天气就声称定位成功。买票、抵达、viewer 选择均不改变这一栏。
短地点常显“现实 · 南京”，长地点允许两行或受控省略，但必须有可聚焦的“详情”入口／设置区完整文本；title 只能补充，不能作为唯一的信息载体。缺地点写“现实地点待识别”，不拿游戏地区补齐。
温度用 `−12°C`／`28°C`，未知写“温度暂无”；模拟不编温度。来源常显“联网／缓存／模拟”，刷新时保留已有来源并附“更新中”；缺观测时间写“气象时刻暂无”，不能把 fetchedAtMs 冒称实测时刻。
顶部精简显示来源与 HH:mm，完整详情区显示地点、数据时刻、获取时间、供应商与错误；跨日／缓存须附日期，地点时区格式由天气 helper 提供并标清，不自行新增时区／游戏时间逻辑。
scene 名称与行政地址／场景天气由渲染标签负责，使用已提交 currentRegion 对应 SceneSite。旅行中仍是出发景点，在途遮层注明目标；只有保存确认发布抵达快照后才换景点和天气。

## 5. 设置中的 12 区只读天气查看器

入口固定文案“查看各水域天气”，与“现实所在地天气／刷新现实天气”分区。组件只拿只读 sites、entries selector、受控 `viewRegionId`／onViewRegionChange 和天气角色提供的 refresh 能力，不拿整个 game 对象或任何 travel／visit／unlock／资产写命令。
查看选择默认可取当前区，只存在设置内存态；关闭／重开不要求新增存档字段。12 个现有 regionId 全部可选，未解锁区仅标“未解锁 · 可查看天气”，不禁用、不显示“已到访”，不混入机票按钮。
420×350：单列区选择器（完整 12 项、原生 select 或等价键盘控件）＋当前条目详情＋单条刷新；640×490：可用左侧可滚动地区列表与右侧详情。仅 PanelWindow 内容滚动，查看器不再套多层固定高滚动区。
详情顺序为地区／代表地点、完整行政地址、天气与温度、来源／气象时刻／获取时间、状态与刷新。未解锁不遮地名；长地址自然换行，数字和单位不拆开；无需同时塞下 12 份详细卡片。
无“全部强刷”按钮；查看与手动刷新都只委托共享队列，缓存命中／过期提升优先级的判断由天气模块完成，不把“点查看”改成额外定位或全批请求。

| entry／来源状态 | 详情与刷新表现 |
| --- | --- |
| idle／无 Snapshot | “等待获取”；温度／气象时刻暂无；不短暂显示上一所选地区内容 |
| queued | “排队获取”；已有缓存继续带来源展示；同目标重复点击合并，不能重建 controller 插队 |
| refreshing | “正在更新”；保留同地点旧值与来源；按钮 busy／禁用，切区仍可读其他条目 |
| ready＋online | “联网天气”；按完整／partial 实际字段显示，缺项仍为暂无 |
| cached／degraded | “缓存天气 · 更新失败”并列；显示缓存数据时间与可重试时间，不把失败隐藏成成功 |
| 429／retryAtMs 在未来 | “服务暂缓，HH:mm 后可重试”；刷新禁用并说明原因；切区不绕过 origin 等待 |
| timeout／错误／全失败 | 同点有效缓存优先；无缓存明确“模拟天气／暂不可获取”，不编温度；其他地区与单机继续可用 |
| 联网关闭／SceneSite pending | 显示“联网已关闭”或“代表地点天气待配置”；现有缓存可读，网络刷新禁用，不用航线省会替代景点 |

错误码转短中文提示由天气 helper 协调；技术诊断保留在现有诊断区，UI 不输出含坐标或 IP 的新日志。状态与来源分开：queued／refreshing 不是 online，degraded 也不意味着一定没有可用缓存。
