## 下载与运行

先退出旧版，完整解压下载的 `PondClock-2.0.1-x64.zip` 到任意可写的新文件夹，再运行 **PondClock.exe**；resources、locales 和 DLL 都要保留。进度继续读取原专注版PondClock-Focus目录。本次不生成安装器。使用者不需要 Node、pnpm、WebView2 或开发服务器。GitHub分发包附有LICENSE、版权和第三方说明，游戏运行文件与原V2.0.1包一致。

拖顶部时钟条移动；展开按钮切换420×350 / 640×490；图钉置顶，“—”最小化，“×”保存后退出。设置里的“移回屏幕”可找回窗口。功能面板内滚动，Esc收起。

## 专注与钓鱼

- **番茄钟**：填写计划，专注25分钟、休息5分钟。每完整完成一轮奖励一包高级饵（可用于5条成功鱼）。同一归属日完成4轮，奖励一张可积攒的任意目的地免费单程票，每天一次。计划按启动时的电脑日期/时区归属，跨午夜不拆分。
- **普通钓鱼**：主动开始/停止，等待55–125秒，鱼讯20秒。及时点击100%完成捕获；未点击时30%自动判定一次。收获进入鱼篓，不自动卖出；停止或关闭期间不补鱼。高级饵默认关闭，可自行开启。
- **主动抛竿**：渔具店450金币购买15次。每次2或3挥触发收鱼条，空挥不扣次，进入条时扣一次。指针往返，按键或点击收竿；白0%、红10%、黄50%、绿100%成功。6秒超时、取消或失败仍消耗这次。仅游戏有焦点时响应，切出暂停，重开保留原事件；成功只出鱼，品质权重高于普通，不耗普通饵。

番茄钟可在后台继续；休眠、关闭应用暂停，重开手动继续。超过10秒调度缺口会保守暂停，卡顿也可能触发；突然断电可能丢失最近约5秒专注进度。计时表示运行计划，不监控实际工作。免费票保留60–180秒航程。

## 鱼获、物品与经济

17个水域、56种鱼。新增太湖、洞庭湖、嘉陵江、白洋淀、胶东近海；按地区鱼池出现，图鉴记录体长、重量、品质与首次发现。地区代表景点不等于精确生态采样点或垂钓许可。

普通成功捕获的互斥概率：

| 结果 | 概率 | 功能 |
| --- | ---: | --- |
| 鱼 | 74% | 当地供应多则价低，稀少/不产地区价高；满168小时任何鱼卖1金币 |
| 破鞋 | 5% | 卖1金币 |
| 泡水表 | 4% | 直接卖50，或花500修理一次 |
| 网红秘籍 | 2% | 使用后，新钓获且出售时新鲜的前三条鱼按当地市价+50% |
| 锈铁罐 | 3% | 卖3金币 |
| 河蚌壳 | 3% | 卖8金币 |
| 渡口代币 | 3% | 下一组15次主动竿九折，或卖25 |
| 密封饵盒 | 3% | 使用得一包高级饵，或卖30 |
| 磨花指南针 | 3% | 下一张付费机票九折，或卖18 |

漂流瓶暂缓。同类未用优惠/秘籍不能重复激活，第二件道具保留；指南针与代币分别存储，免费票不消耗机票折扣。自动鱼讯先判30%成功，再使用上述捕获表。

修表：40%失败、55%普通机械表卖10–200、4.9%名贵机械表卖1000–9999、0.1%卖10000；结果同笔保存，重开不重抽。秘籍不作用于旧鱼、过期鱼或物品，不叠加。

普通成功捕获的长期平均毛收入约47.42–51.06金币（地区、有/无高级饵与普通保底）；不含饵成本、秘籍、跨区溢价、修表、票券节省。这是统计期望，不是单竿保底。自动每小时收益低于及时手动。为达到约50目标，本版重平衡鱼价与区域品质，**旧库存鲜鱼也使用新市价**，七天规则保留。数值统一在 [平衡配置](src/config/balance.js)，完整矩阵在 [地区报告](docs/v2.0.0/roles/regions/README.md)。

取消数值鱼竿升级；外观鱼竿仍可收藏。旧档导入时原等级归档，按等级一次补偿0/600/3200/12200金币；这是等级估算，不声称历史实付金额。

## 外观与天气

默认恢复1.1.1经典小人。白发披风改为650金币人物拓展包；旧schema1–3迁移赠送权益但不自动装备。水墨包1800金币，包含17水域插画、水墨渔翁与墨竹竿；已有包自动覆盖新增五景。云游/暮色旅人各650，青玉/晨光竿350/500。插画、人物、鱼竿独立搭配，纯外观、全部离线内置，无人民币支付。

场景天气可跟随现实所在地、当前钓点，或手动选择晴/阴/雨/雪。例如广州背景可显示东莞天气。漫游实际抵达后自动跟随目的地天气；飞行途中保留出发地。上方始终显示电脑现实时间与现实所在地天气。雨滴触水涟漪、雪花轻落消融，人物雨具和积雪随场景天气变化。

IP只累计解锁，不自动瞬移；可信城市匹配才解锁新增细区，省级结果仍归原宽区。“看看远方的天”可查看17水域天气，不买票或切背景。

## 记忆与兼容

专注版存档：`%APPDATA%\PondClock-Focus\saves`，schema4、editionId `first-focus`。首次启动会只读旧 `%APPDATA%\PondClock\saves`，将原始槽备份到新目录后复制迁移，**不写旧目录**。已有专注版进度则不访问旧档；未来版本/封装和同修订冲突停止自动复制。旧付费航程保留原票价与到达时间。设置可导出/导入备份，换电脑前先导出；新版存档不兼容旧版程序。

金币、物品、修表结果、专注奖励、通票、优惠、外观和旅途经双槽原子保存确认后生效；关键奖励和付款凭据持久去重。重开后普通钓鱼停止、专注暂停、未结主动条暂停，航程继续。

## 联网与离线

定位依次使用ipapi / IPWhois；天气来自Open-Meteo。服务会看到公网IP，天气还收到大致坐标；本机不保存完整IP。切回窗口、恢复联网和保持打开每2分钟复查定位，支持手动刷新。设置可关闭联网。未读取Windows任务栏的私有天气缓存。

现实与17钓点天气共享有界队列：最多2路运输、至少1秒启动间隔、15分钟新鲜度、最长6小时缓存；429遵守冷却。断网照常游戏，界面标明缓存/待获取，不以模拟天气伪装联网成功。
